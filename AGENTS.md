# Instructions for AI coding agents

This project's instructions for AI coding agents (Claude Code, OpenAI Codex and similar) are in [CLAUDE.md](CLAUDE.md). **Read it in full before you change anything.** It covers the layout, the rules for editing cards, the privacy rules and the checks to run after every change; the same rules apply whichever agent you are.

Start with [README.md](README.md), then [docs/design-principles.md](docs/design-principles.md) and [docs/editing-the-story.md](docs/editing-the-story.md). The developer of this kit uses Claude Code, so the guides' example prompts are written for it; adapt them to your tool.
